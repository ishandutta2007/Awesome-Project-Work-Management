# Awesome-Project-Work-Management

## Top Project & Work Management Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Team Task Orchestration, Portfolio Visibility & Self-Hosted Collaboration*  

**Last updated: October 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Project & Work Management**. These tools enable teams to plan work, assign tasks, track progress, and align execution with strategic goals—providing the visibility and coordination needed to deliver projects on time and within budget.



**Examples** include Workday Project and Work Management, Asana, Monday.com, Smartsheet, Wrike, ClickUp, Notion, Airtable, Basecamp, and Trello (the category leaders).



**Open-source emphasis**: This section is expanded with active projects for self-hosted project management, collaborative workspaces, and database-driven applications—ideal for teams building sovereign work management infrastructure without per-seat licensing lock-in.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Workday Project and Work Management](https://www.workday.com/)**  

  Unified project and work management within Workday's enterprise suite, seamlessly connected to HCM, Financial Management, and Spend Management; supports planning work areas with phases/tasks/milestones, staffing from talent pools based on skills and availability, tracking labour and non-labour costs against budget, billing customers by milestone, and analyzing project profitability and resource utilization through built-in dashboards .



- **[Asana](https://asana.com/)**  

  Work management platform built on a task-project-goal hierarchy; supports List, Board, Timeline, and Calendar views, goal tracking for strategic alignment, and automation rules for workflow efficiency .



- **[Monday.com](https://monday.com/)**  

  Visual work OS with customizable boards, status columns, and automation; supports Gantt timelines with dependency columns and is known for low onboarding friction for non-technical teams .



- **[Smartsheet](https://www.smartsheet.com/)**  

  Spreadsheet-driven project management with all four dependency types, critical path, and baseline comparisons; best suited for traditional PM teams migrating from Microsoft Project .



- **[Wrike](https://www.wrike.com/)**  

  Enterprise work management with Gantt charts, resource management, and portfolio views; supports baseline tracking and cross-project reporting for professional services teams .



- **[ClickUp](https://clickup.com/)**  

  All-in-one productivity platform supporting all four dependency types, critical path highlighting, and multiple views (List, Board, Gantt, Calendar); combines task management with docs, whiteboards, and sprint capabilities .



- **[Notion](https://www.notion.com/)**  

  All-in-one workspace combining wikis, docs, databases, and project management with flexible block-based pages and template ecosystem.



- **[Airtable](https://www.airtable.com/)**  

  Relational database-spreadsheet hybrid with views, automations, and interfaces for building custom work management applications.



- **[Basecamp](https://basecamp.com/)**  

  Project management and team communication with message boards, to-do lists, schedules, and file storage in a simple, opinionated interface.



- **[Trello](https://trello.com/)**  

  Kanban-based work management with boards, lists, and cards for visual task tracking; widely adopted for its simplicity.



## Open-Source GitHub Projects



- **[Plane](https://github.com/makeplane/plane)**  

  Leading open-source project management platform (AGPL-3.0, 47,800+ GitHub stars) positioned as a Jira/Linear/Monday/ClickUp alternative; features work items, Cycles (sprints) with burn-down charts, Modules, Pages for wiki/docs, and five layout views (List, Board, Spreadsheet, Gantt, Calendar); self-hostable via Docker with PostgreSQL, Redis, RabbitMQ, and MinIO.



- **[OpenProject](https://github.com/opf/openproject)**  

  Full-featured open-source project management suite (GPL-3.0) with tasks, Gantt charts, Agile boards (Kanban/Scrum), roadmaps, time tracking, and collaboration features; available on-premises or cloud; a powerful Jira alternative for product, project, and portfolio management.



- **[LibrePlan](https://github.com/LibrePlan/libreplan)**  

  Open-source web-based project management platform (AGPL) focused on project planning, resource allocation, capacity management, issue/risk tracking, and governance; v1.6.0 adds issue/risk logs, project document repositories, and pipeline overview; designed for self-hosted and sovereign cloud deployments .



- **[Leantime](https://github.com/Leantime/leantime)**  

  Open-source project management system (AGPL) combining design thinking, lean methodology, and Agile practices; features kanban boards, lists, Gantt charts, goal tracking, milestone management, document manager, and LDAP integration; self-hosted free version available (limited to 150 tasks) .



- **[Tuleap](https://github.com/Enalean/tuleap)**  

  Open-source application lifecycle management platform (GPL) for software development teams; features ticketing/bug tracking, Agile planning, document management, version control, CI, and customizable workflows; available on-premises or cloud .



- **[Focalboard](https://github.com/mattermost-community/focalboard)**  

  Open-source, self-hosted alternative to Trello, Notion, and Asana; provides kanban boards, table views, and card-based task management with multi-user collaboration.



- **[Wekan](https://github.com/wekan/wekan)**  

  Open-source Trello-like kanban board (MIT); provides real-time collaborative boards with cards, lists, swimlanes, and member assignments.



- **[Kan](https://github.com/kanbn/kan)**  

  Open-source Trello alternative with board visibility controls, workspace members, Trello imports, labels, comments, activity log, and templates; Docker-deployable with PostgreSQL and optional Redis for rate limiting .



- **[Taiga](https://github.com/kaleidos-ventures/taiga)**  

  Agile project management tool for Scrum and Kanban teams; features epics, user stories, tasks, issues, and sprint management.



- **[NocoDB](https://github.com/nocodb/nocodb)**  

  Open-source Airtable alternative (AGPL) that connects to existing databases and provides grid, kanban, calendar, and gallery views; self-hostable and REST API-enabled; positioned as a database UI with practical-level completeness rather than a full Airtable replacement .



- **[AFFiNE](https://github.com/toeverything/AFFiNE)**  

  Open-source knowledge base combining block documents and infinite canvas (Notion + Miro style); supports offline use, self-hosting via Docker, and AI-assisted creation; suitable for teams wanting an integrated workspace for docs and visual planning .



### Additional Strong Open-Source Options



- **Redmine** — Classic open-source issue tracking and project management with multiple projects, Gantt charts, calendars, and flexible role-based access.

- **Kanboard** — Simple visual task board with kanban-style project management, swimlanes, and plugin support for smaller teams.

- **Vikunja** — Lightweight to-do app with kanban, Gantt, List, and Table views; self-hosted with Docker for small teams seeking simplicity.

- **AppFlowy** — Open-source Notion alternative (AGPL-3.0) with to-do lists, project tracking, and block-based editor for knowledge management.



**Frameworks for building custom systems**: Combine **Plane** for modern AI-native project workspaces with sprints and docs, **OpenProject** for full lifecycle portfolio and Gantt-based planning, **LibrePlan** for resource-constrained capacity management and governance, and **NocoDB** for database-driven work applications in a fully self-hosted project and work management stack.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Project and work management platforms handling team data must comply with applicable privacy regulations and organizational governance policies; access controls and audit logging are important for enterprise deployments.

- Self-hosted open-source solutions vary significantly in scope—Plane and OpenProject provide broad project management capabilities, while Focalboard and Kan focus on visual boards; full enterprise work management with strategic alignment, resource capacity planning, and financial integration typically requires commercial platforms like Workday.

- Verify license terms for commercial use; Plane uses AGPL-3.0, OpenProject uses GPL-3.0, LibrePlan uses AGPL, and Leantime uses AGPL with paid hosted plans.
